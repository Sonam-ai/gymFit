# gymFit 💪

An AI-powered fitness web application built with React and Material UI that helps users discover exercises, calculate BMI, generate personalized workouts, and track fitness goals through an interactive and responsive user experience.

---

## 🚀 Features

- 🔍 Search exercises by name, body part, target muscle, or equipment
- 🤖 AI-powered workout recommendations
- 🌗 Dark & Light mode support
- 📊 BMI Calculator
- ❤️ Save favorite workouts
- 📱 Fully responsive modern UI
- ⚡ Fast exercise fetching using ExerciseDB API
- 🎯 Personalized fitness experience
- 🎨 Smooth animations and clean UX

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Material UI (MUI)
- React Router DOM

### APIs
- ExerciseDB API
- AI Integration API

### Other Tools
- LocalStorage
- RapidAPI
- Vercel / Netlify

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sonam-ai/gymFit.git
```

Navigate to project folder:

```bash
cd gymFit
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file in the root directory and add:

```env
REACT_APP_RAPID_API_KEY=your_api_key
```
